# Quiz de Tiro y Armas

Quiz de estudio con 6 unidades y un examen final integrador: opción múltiple, verdadero o falso, completar, ordenar e identificación de partes.

Material de estudio para alumnos. No es un HTML oficial de la Prefectura Naval Argentina.
